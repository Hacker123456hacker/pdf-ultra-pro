AI YouTube
Daily Agent

Automatic Hindi video creation, narration, rendering and YouTube upload. The MP4 is also retained as a GitHub Actions artifact.

Pipeline

🤖 AI script
Gemini creates topic, title, narration and scenes.
🖼️ Visuals
Wikimedia Commons assets with fallback graphics.
🎙️ Voice
Hindi narration via edge-tts.
🎬 Render
FFmpeg creates a 1080×1920 MP4.
▶️ YouTube
OAuth upload; default visibility is private.
📱 Phone
Download the Actions artifact to save the MP4 locally.

Setup

1. Open the repository's Settings → Secrets and variables → Actions.
2. Add GEMINI_API_KEY, YOUTUBE_CLIENT_SECRET_JSON and YOUTUBE_REFRESH_TOKEN.
3. Run Actions → AI YouTube Daily Agent → Run workflow once with YouTube visibility set to private.
4. After testing, set VIDEO_PRIVACY to public or unlisted as desired.

Important

Never paste API keys or OAuth refresh tokens into this HTML page or commit them to GitHub. A YouTube API key can read public data, but video uploads require OAuth authorization.
