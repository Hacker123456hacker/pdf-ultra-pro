Frequently asked questions

Is my file actually uploaded anywhere?▾

No. Every tool on this site uses JavaScript libraries (pdf-lib, pdf.js, and a few others) that run inside your browser tab. Files are read with the File API and processed locally — this site doesn't have a backend to upload to.

Is PDF Ultra Pro really free?▾

Yes, every tool is free with no sign-up. The site is supported by non-intrusive advertising placeholders you can see throughout the page.

Why don't Protect PDF and Unlock PDF work yet?▾

Real PDF encryption/decryption needs a properly vetted crypto implementation, which isn't something this project fakes. Open either tool's page for the full explanation and links to alternatives that work today.

How accurate is OCR PDF?▾

It depends heavily on scan quality and language. It runs entirely on your device using an open-source OCR engine, and supports English, Spanish, French, German, Portuguese, Hindi, Arabic and Simplified Chinese.

Does this work on mobile?▾

Yes. The interface is fully responsive, and you can even install PDF Ultra Pro to your home screen as a lightweight app.
