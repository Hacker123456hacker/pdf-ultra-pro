Frequently asked questions

Privacy & security

Do you store or see my files?▾

Supported file-processing code reads selected files in your browser and is designed to process them locally; the site is not designed to upload those files to our own application server. The page may still make network requests to load scripts, libraries, fonts, hosting resources or advertising. Avoid using the site if your device or browser is not trusted.

Can I use this offline?▾

You may be able to install the site as an app, but offline availability is limited to resources already cached by your browser. Most tools also depend on external JavaScript libraries, so do not assume every tool will work offline. Test offline mode before relying on it.

Is it safe to process sensitive documents here?▾

Supported tools are designed to process selected files locally, rather than upload them to our server. However, this does not mean the entire website makes no network requests: hosting, external libraries and advertising may contact third-party services. For highly sensitive documents, use software you control and have independently verified.

Limits & compatibility

What's the maximum file size?▾

100MB per file, and up to 40 files in a batch for tools that support multiple files. These limits exist to keep your browser responsive, since processing uses your device's own memory.

Which browsers are supported?▾

Current versions of Chrome, Firefox, Edge and Safari, on both desktop and mobile.

Why can't I selectable-text after using Compress PDF?▾

Compress PDF works by re-rendering each page as a compressed image, which is what makes it effective on scanned or image-heavy PDFs. That process rasterizes any text, so it's not the right tool if you need to keep selectable, searchable text \u2014 in that case, try reducing embedded image size manually instead.

Missing tools

Why isn't Protect/Unlock PDF available yet?▾

Real PDF password protection and removal require robust encryption support that isn't reliably available in the open-source libraries this site uses client-side. We'd rather mark it "Coming soon" than ship something that doesn't actually protect your file.

How accurate are Word/Excel/PowerPoint conversions?▾

The current browser-based converters extract supported document or presentation content and create a simplified PDF. They do not reproduce the full layout, fonts, charts, images or slide formatting of Microsoft Office. Check each converter's page description and verify the downloaded PDF before relying on it.
